# Mental Health Companion

A web-based mental health support chatbot built using Flask.

## Features
- Detects depression, anxiety, stress keywords
- Provides relaxation tips
- Provides motivational support
- Crisis response for sensitive keywords

## Technologies Used
- Python
- Flask
- HTML & CSS
- Machine Learning (Vectorizer + Model)

## How to Run
1. Install Python
2. Download project
3. Open terminal in project folder
4. Run: pip install -r requirements.txt
5. Run: python app.py
6. Open http://127.0.0.1:5000
